# Batter Container Stock Dashboard — Team Shared Version

Upload index.html to GitHub Pages. Share the URL with your team.

## Setup (5 steps)
1. Go to github.com → Sign up free
2. Click + → New repository → name it stock-dashboard → Public → Create
3. Upload index.html → Commit changes
4. Settings → Pages → main branch → Save
5. Your URL: https://YOUR-USERNAME.github.io/stock-dashboard

## How sync works
- Edit any cell → yellow = unsaved
- Click Save & Sync Team → pushes to shared storage
- Team clicks Refresh Data → sees latest data
- Auto-refreshes every 60 seconds
